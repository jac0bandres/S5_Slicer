# Earlier S4 and S5 work

The active S³ implementation is at the repository root. This directory keeps
the earlier S4 reference and S5 slicer for comparison and provenance.

- [`s4/s4_reference.py`](s4/s4_reference.py) contains the extracted S4 reference
  methods used by S³'s Cura reformation adapter.
- [`s5/`](s5/) contains the earlier S5 slicer, its documentation, sample models,
  plots, and benchmark results. See the [S5 README](s5/README.md).

The root [`config/`](../config/) remains the active Cura configuration for S³.
