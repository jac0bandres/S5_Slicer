# S5_Slicer benchmark report

Per-stage timing and correctness of the optimized S5 pipeline (`S5.py`) against the naive S4 reference (`s4_reference.py`), generated by `bench_report.py` from the `bench_sweep.py` runs under `bench_results/`.

## Environment

- **Platform:** Linux-6.12.85+deb13-amd64-x86_64-with-glibc2.41
- **Python:** 3.12.0
- **Packages:** numpy 2.4.4, scipy 1.17.1, pyvista 0.47.3, tetgen 0.8.3, igl unknown
